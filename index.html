FAQ

Does it actually run scripts in-game?

The payload DLL, Lua 5.1 runtime and HttpGet pipeline are all real and compiled. Attaching to the live client requires bypassing Roblox's anti-cheat, which needs a driver-level component that isn't part of this build yet.

Where does it install?

%LocalAppData%\Programs\Syntex by default. Support files live in %AppData%\Syntex. Nothing touches your Desktop except the optional shortcut.

Is there a Mac or mobile version?

Windows x64 only for now.
